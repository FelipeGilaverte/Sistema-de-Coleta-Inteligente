# EcoCondomínio IA

MVP acadêmico de um sistema inteligente para coleta de resíduos em condomínios.

O projeto utiliza dados fictícios para demonstrar como sensores e inteligência
artificial podem ajudar a prever a lotação das lixeiras, priorizar pontos de
coleta e reduzir deslocamentos desnecessários.

## Demonstração

[Abrir o dashboard](https://ecocondominio-ia.felipegilaverte.chatgpt.site)

## Funcionalidades do MVP

- indicadores de volume coletado, reciclagem e economia estimada;
- comparação entre os últimos 7 e 30 dias;
- alertas de pontos com ocupação crítica;
- recomendação fictícia de rota gerada por IA;
- visão explicativa preparada para apresentação;
- interface responsiva para computador e celular.

## Executar localmente

O dashboard é uma página estática. Abra `index.html` no navegador ou inicie um
servidor HTTP local na raiz do repositório.
